Local paper library

symelib (elib) is a local PDF / manuscript manager: ingest, PubMed-primary then Crossref metadata, SQLite FTS5 search, and a TUI. Optional agents/RAG path via Postgres + pgvector.

Repository

Ingest

PDF processing (PyPDF2; optional GROBID). Library lives under ~/elibrary.

Metadata

PubMed → Crossref → honest local fallback, with quality tracking.

Search

SQLite FTS5 plus metadata filters; elib enrich / check-metadata.
