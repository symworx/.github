SymWorx is a modular computational stack for biosignal analysis, training load, nonlinear dynamics, and classical ML — with a Rust kernel, Python bindings, and a keyboard-driven terminal UI (symview). Built for research, education, and portable inference from workstations toward the edge.

Focus

We put dynamical systems methods, signal processing, and classical ML into one inspectable stack for research workflows and constrained hardware. Build reproducible analyses of biosignals and performance data, quantify nonlinear structure, and train simple models you can export — without bolting together a new stack for each study.

Physiological & biomechanical

Biosignals (PPG, respiration), gait and CPG models, training load and multi-source performance time series, and spatial trajectory analysis.

Classical ML & stats

Logistic (binary/OVR), Naive Bayes, k-NN, rule lists, k-means, metrics/ROC-AUC, plus OLS/Ridge/LDA/PCA behind optional linalg — with model export for C, mobile, and web.

Nonlinear dynamics

RQA, entropy and complexity, embedding, DMD and SINDy, plus signal foundations — filters, peaks, sparse sensing, and Kalman tools.

Embedded & portable

Host-side streaming, a path toward microcontrollers, and the same methods via Python for teaching and rapid prototyping.

Terminal UI · symview

Day-to-day interactive work runs through symworx-tui (binary symview). From Home:

  • 1 · BioSym — Import · Explore · Dynamics (RQA) · Generate
  • 2 · StatsSym — Import · Lab (classical ML / stats) · Generate
  • 3 · LoadSym — Workouts, calendar trends, load recommendations
  • 4 · SpatialSym — Trajectories, space metrics, decision views

When the monorepo is available locally: 

cargo run -p symworx-tui --bin symview
symworx-tui on develop

Crates

Domain and foundation crates inside symworx/symworx (default branch develop).

  • symworx-tui TUI · symview Interactive terminal UI: BioSym, StatsSym ML lab, LoadSym, SpatialSym.
  • symworx-stats classical ML Stats + ML: logistic, NB, k-NN, rules, k-means, PCA, model export.
  • symworx-biosym biology · biomechanics PPG, respiration, gait analysis, and central pattern generators.
  • symworx-loadsym training load ACWR/TSS-style load, FIT, nutrition, and the symload CLI.
  • symworx-dynamics nonlinear dynamics RQA, embedding, entropy, DMD, SINDy, and control tools.
  • symworx-signal signal processing Filters, peaks, sparse sensing, Kalman family, resampling.
  • symworx-spatialsym spatial analysis 2D trajectories and post-hoc spatial decision modeling.
  • symworx-core foundation Core re-exports and shared utilities across the stack.

Also: io, embed, loadsym-db, math, backend, error, and Python bindings.
