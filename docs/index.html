SymWorx is a multi-use computational framework with a Rust kernel and Python bindings — built for security, robustness, and portability from microcontrollers to the cloud. Open development lives in a single monorepo.

Security

Minimize unsafe code, reduce unintended execution paths, and lower supply-chain risk.

Robustness

Predictable behavior, strong typing, and explicit error handling across the stack.

Scalability

Consistent APIs for embedded, desktop, scientific, and educational workloads.

Crates

Domain and foundation crates inside symworx/symworx.

  • symworx-biosym biology · biomechanics Physiological signals (PPG, respiration), gait analysis, and central pattern generators.
  • symworx-loadsym training load Training load, periodization, ACWR/TSS, monotony/strain, and nutrition modeling.
  • symworx-spatialsym spatial analysis Sport-agnostic 2D trajectory analysis and post-hoc spatial decision modeling.
  • symworx-dynamics nonlinear dynamics RQA, embedding, entropy, DMD, Koopman/EDMD, and LTI control tools.
  • symworx-signal signal processing Filters, peaks, sparse sensing, interpolation, and resampling.
  • symworx-core foundation Core re-exports and shared utilities across the simulation crates.
  • symworx-tui symview Terminal UI for biosignal exploration, dynamics, and load analysis.
  • symworx-io I/O Canonical I/O for biosignals and activity data (CSV, Parquet, FIT, email).

Also in the monorepo: loadsym-db, stats, math, embed, backend, error, and Python bindings.
