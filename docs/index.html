SymWorx is a modular computational framework with a Rust kernel and Python bindings — for mathematical signal processing, nonlinear dynamics, and simulation. Explore data interactively with the terminal UI (TUI) — symview — for biosignals, dynamics workflows, and training load. Built for security, robustness, and portability from microcontrollers to the cloud.

Focus

Dynamical systems theory and rigorous signal methods as usable pipelines — inspectable, extensible, and ready for noisy field data and constrained devices.

Physiological & biomechanical

Biosignals (PPG, respiration), gait and movement modeling, central pattern generators, training load and multi-source performance time series, and spatial trajectory analysis.

Nonlinear dynamics

RQA/CRQA, entropy and complexity measures, embedding, DMD and Koopman methods, plus signal foundations — filters, peaks, sparse sensing, and resampling.

Embedded systems

Portable engines for microcontrollers and bare-metal, host-side streaming (serial / simulators), and the same methods via Python for research and rapid prototyping.

Terminal UI · symview

Day-to-day interactive work runs through the TUI crate symworx-tui (binary symview): convert and load physiological signals, visualize in the terminal, explore nonlinear dynamics (including RQA), and run LoadSym workflows for workouts and trends. 

cargo run -p symworx-tui --bin symview
symworx-tui docs

Crates

Domain and foundation crates inside symworx/symworx.

  • symworx-biosym biology · biomechanics Physiological signals (PPG, respiration), gait analysis, and central pattern generators.
  • symworx-loadsym training load Training load, periodization, ACWR/TSS, monotony/strain, and nutrition modeling.
  • symworx-spatialsym spatial analysis Sport-agnostic 2D trajectory analysis and post-hoc spatial decision modeling.
  • symworx-dynamics nonlinear dynamics RQA, embedding, entropy, DMD, Koopman/EDMD, and LTI control tools.
  • symworx-signal signal processing Filters, peaks, sparse sensing, interpolation, and resampling.
  • symworx-core foundation Core re-exports and shared utilities across the simulation crates.
  • symworx-tui TUI · symview Interactive terminal UI (symview): load and visualize biosignals, run RQA/dynamics, and LoadSym workout analysis.
  • symworx-io I/O Canonical I/O for biosignals and activity data (CSV, Parquet, FIT, email).

Also in the monorepo: loadsym-db, stats, math, embed, backend, error, and Python bindings.
