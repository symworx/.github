SymWorx began as a modular stack for biosignal analysis, training load & periodization, nonlinear dynamics, and machine learning — written in Rust with Python bindings, aimed at bare metal, mobile, and web. The product surface now also includes tools for literature and text-based insights for scientists, engineers, and product teams.

Repositories

Orient here; install, crates, and quickstarts live in each product repo when it is open.

  • symworx pending public release · develop Inspectable Rust kernel with Python bindings for biosignals, training load, nonlinear dynamics, and classical ML — plus the symview TUI. Same methods from research workstations toward constrained hardware, without a new toolchain per study. Install and crate map land in the monorepo when it opens.
  • symworx-elibrary public beta · elib Local PDF library: ingest, PubMed → Crossref → local metadata, full-text search, reading lists, and an optional agents/RAG path. Day-to-day work via the elib CLI and TUI. Setup and quickstart are in the product repo.
  • symworx-insights pending public release Turn notes, analyses, and research artifacts into draft blog and social copy — human-editable narrative alongside the scientific stack and literature library.
