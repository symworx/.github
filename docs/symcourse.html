Course scaffold

symcourse creates a course repository: layout, runtime, and identity. Agent packs come from symkit. The default is course- and university-agnostic. UNCG MSIA / IAN is an optional overlay (--preset msia), not the product.

Repository symkit

From a clone

cargo install --locked --path .
./cli/symcourse --help

Catalog and templates are embedded at compile time. The repo is private; public pages here only describe the product.
