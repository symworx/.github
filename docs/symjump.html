Terminal jump list

symjump (binary sjmp) is pinned places and a few actions for a real terminal. Not an emulator, not a project.el replacement, not git/docker aliases. eval "$(sjmp init bash)" stays off when $INSIDE_EMACS is set.

Repository

Install

cargo install sjmp
sjmp                       # writes ~/.config/symjump/favorites.toml
eval "$(sjmp init bash)"   # jmp; binds M-p / M-P / M-x

Places

Favorites that travel across Kitty, foot, or a tmux pane without rewriting bashrc paths.

Actions

Toolbox destinations and agent exec. Meta bindings, not Control.
