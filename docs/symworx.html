Analysis stack

symworx/symworx is a modular computational stack for biosignal analysis, training load, nonlinear dynamics, and classical ML — Rust kernel, Python bindings, and a keyboard-driven TUI (symview). Same methods from notebooks to constrained devices.

Repository symview TUI

Focus

Physiological & biomechanical

PPG, respiration, gait and CPG models, training load, spatial trajectories.

Classical ML & stats

Logistic, Naive Bayes, k-NN, rule lists, k-means, ROC/AUC, OLS/Ridge/LDA/PCA, model export.

Nonlinear dynamics

RQA, entropy, embedding, DMD, SINDy, filters, peaks, sparse sensing, Kalman tools.

Embedded & portable

Host-side streaming, a path toward microcontrollers, Python for teaching.

Terminal UI · symview

Day-to-day work runs through symworx-tui (binary symview). From Home:

  • 1 · BioSym — Import · Explore · Dynamics (RQA) · Generate
  • 2 · StatsSym — Import · Lab (classical ML / stats) · Generate
  • 3 · LoadSym — Workouts, calendar trends, load recommendations
  • 4 · SpatialSym — Trajectories, space metrics, decision views

Crates

Domain and foundation crates in this repository.

  • symworx-tui TUI · symview BioSym, StatsSym ML lab, LoadSym, SpatialSym.
  • symworx-stats classical ML Logistic, NB, k-NN, rules, k-means, PCA, model export.
  • symworx-biosym biology · biomechanics PPG, respiration, gait, central pattern generators.
  • symworx-loadsym training load ACWR/TSS-style load, FIT, nutrition, symload.
  • symworx-dynamics nonlinear dynamics RQA, embedding, entropy, DMD, SINDy, control.
  • symworx-signal signal processing Filters, peaks, sparse sensing, Kalman family.
  • symworx-spatialsym spatial analysis 2D trajectories and post-hoc spatial decisions.
  • symworx-dbsym study catalog Per-study / edge catalog (SQLite).

Also: io, embed, loadsym-db, math, core, backend, error, and Python bindings.
